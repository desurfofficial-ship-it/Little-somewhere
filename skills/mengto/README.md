# MengTo/Skills for LITTLE SOMEWHERE

**Enhancement only.** The repository’s `AGENTS.md` and art-direction docs remain the source of truth.

## Install

```bash
npx skills add MengTo/Skills
```

Or clone and load only the folders you need (the full library is large).

## Most relevant categories for this project

- `agent-skills/3d/` — water, lighting, virtual tour, high-resolution textures, modular buildings, etc. Use as technique libraries, then adapt to the storybook diorama style.
- `agent-skills/game-development/` — isometric ARPG patterns, camera controls, level authoring, enemy/monster systems, ship & test workflows. Useful patterns; rewrite to match LITTLE SOMEWHERE’s cozy life-sim systems.
- `agent-skills/web-design/` and illustration skills — for HUD polish and any 2D storybook elements.

## Rules when applying MengTo skills

1. Never import a skill’s demo style if it conflicts with PREMIUM HANDCRAFTED STORYBOOK DIORAMA.
2. Keep the three-layer architecture intact.
3. Prefer procedural geometry and shared palette materials over dropping in external meshes.
4. Run the project’s verification gates after any visual or game-system change.
