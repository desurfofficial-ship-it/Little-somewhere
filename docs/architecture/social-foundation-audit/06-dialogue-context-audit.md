## 7. Findings

- **R-05 (P2) — echo asserts firsthand participation to rumor holders.** `collectUnmentionedSharedTags`/`topicRequiresTagOverlap` ignore `provenance`; gossip propagation copies `shared_featured_reading` memories to warm neighbors preserving tag+eventId with `provenance: 'secondhand'|'rumor'`. End-to-end repro: mina (never attended) receives the rumor → `buildResidentDialogue('mina')` selects the echo and renders *"I keep thinking about the little while **we spent together** at Linden Book Nook… we should do that again sometime."* Legacy celebration/gift topics branch on `provenance !== 'firsthand'` ("X was just telling me…") — the echo, whose own header claims to follow "exactly the proven epilogue/celebration pattern", has **no provenance branch**. Not a hidden-info leak (the player knows the visit happened; the NPC legitimately knows via gossip) — an immersion/truthfulness defect. Likelihood medium (gossip of interaction memories to warm pairs is routine; 6-day window). Fix: filter `provenance === 'firsthand'` in `collectUnmentionedSharedTags` + add the condition field (or add the legacy provenance branch to the text). **Exposure multiplies when LR-3 adds the second `shared_*` tag.**
- **R-06 (P2)** — band-claim imprecision + the one reachable inversion (§1).
- **P3 batch:** SF4-04 vacuous; R2 reunion boost is a uniform band-wide +3 that cannot reorder anything by itself (40/40 staged worlds: fired every time, changed selection 0 times — header wording overstates; doc 22's "clears small history penalties" is the accurate description); echo memory spec duplicated ×3 (topic condition / engine surfacing branch / buildText — drift would silently break the mention flip); `scripts/topic_snapshot_runtime.json` stale at 85 topics (manual artifact, not test-consumed); engine clamp propagates a hostile NaN boost (`Math.max(-5, Math.min(5, NaN)) === NaN` → NaN score — producer never emits NaN; `Number.isFinite` hardening note); doc 22 "588/588" header drift.
